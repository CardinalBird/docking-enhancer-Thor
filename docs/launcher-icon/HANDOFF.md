# Launcher icon v2 — handoff for Claude Code

New Control Switch launcher icon, designed to sit naturally in Cocoon Shell on the AYN Thor.
Everything here is generated by `gen.py` from one set of numbers; the Android files are ready to
drop in. Design canvas (for reference only): https://claude.ai/artifact/5R6yZs2sUfhN96g3iykFjo

![preview](png/preview.png)

## The design

- **Concept "Mirror":** a white Pro-style controller (wide body, long splayed grips, offset sticks:
  left stick high + d-pad low, face buttons high + right stick low, small − / +) in front of a
  50 %-alpha copy of itself, offset up-left. Reads as "one controller's input mirrored to another".
- **Ground:** emerald gradient, `#43C78B` (top) → `#11935F` (bottom), vertical. A deeper green than
  Cocoon's brand green `#64BF75`, using the same light-top/deep-bottom treatment as Cocoon's folder
  tiles.
- **Glyph:** solid white with details cut out to the ground (Cocoon's icon style), plus a flat drop
  shadow (black, 14 % alpha, offset 2.2 units down) on the front controller.
- **Grid:** 108×108 adaptive-icon viewport; the whole glyph stays inside the 66 dp safe circle
  (farthest pixel 32.7 units from centre).
- The ghost controller has the front's silhouette (grown by 2.5 units) cut out of it, so the
  foreground layer is fully transparent: no background-coloured outline, and it works over any
  launcher ground and in the themed (monochrome) icon.

## Task for Claude Code

Repo: `control-switch` (Kotlin/Compose, see `AGENTS.md`). Branch off `main` first
(e.g. `feat/launcher-icon-v2`); commit only when the user asks.

1. **Replace the launcher icon** — copy these over `android/app/src/main/res/`:
   - `android/res/drawable/ic_launcher_background.xml` → `res/drawable/` (replaces flat `#0080B3`)
   - `android/res/drawable/ic_launcher_foreground.xml` → `res/drawable/` (replaces the line-drawn pad)
   - `android/res/drawable/ic_launcher_monochrome.xml` → `res/drawable/` (**new**)
   - `android/res/mipmap-anydpi/ic_launcher.xml` and `ic_launcher_round.xml` → `res/mipmap-anydpi/`
     (only change: `<monochrome>` now points at `@drawable/ic_launcher_monochrome` instead of the
     foreground, because the foreground now carries a shadow the themed icon must not have)
   - `android/res/mipmap-xxxhdpi/ic_launcher.png` and `ic_launcher_round.png` → `res/mipmap-xxxhdpi/`
     (legacy fallbacks; minSdk 28 always uses the adaptive icon, these just stay consistent)
2. **Lint:** the two long-path vectors carry `tools:ignore="VectorPath"` with a comment saying why
   (AGENTS.md: suppress at the site with a reason). The background uses an `aapt:attr` gradient,
   fine at minSdk 28. Run `./gradlew :app:lintDebug` (warnings are errors) and
   `./gradlew :app:assembleDebug`.
3. **Check on the Thor:** install, then look at the icon in Cocoon Shell's grid (light and dark),
   the stock launcher, and with themed icons on. The "Add to home screen" shortcut
   (`AdditionalSettingsScreen`) uses the launcher icon, so it updates on its own — re-add a
   shortcut to see it.
4. **Optional, ask the user first:** `compose/ControlSwitchLogo.kt` is the same icon as a Compose
   `ImageVector` (`ControlSwitchLogo.Tile` with the rounded emerald tile, `ControlSwitchLogo.Glyph`
   without). It is for in-app branding (e.g. the header mark in `MirrorScreenParts.kt:67`, which
   currently shows `R.drawable.ic_controller`). Don't add it unless it gets used. Leave
   `ic_controller` itself alone: `Player1Screen` uses it to picture a controller, not as branding.
5. **Docs:** keep this folder in the repo as `docs/launcher-icon/` (source of truth); optionally swap
   the README's icon for `png/control-switch-icon-512.png`.

## Other formats in this folder

| Path | Use |
| --- | --- |
| `svg/control-switch-icon.svg` | Full-bleed master, identical to the Android layers |
| `svg/control-switch-icon-rounded.svg` | Cocoon-style rounded tile (rx 26/108) for web, README, Silk Pod / theme art |
| `svg/control-switch-glyph.svg` | Glyph only, transparent |
| `svg/control-switch-glyph-mono.svg` | One-colour glyph (alpha only), no shadow |
| `css/control-switch-logo.css` | Colour tokens + `.cs-logo` (whole icon) and `.cs-logo-tile` (glyph on a CSS gradient tile) |
| `compose/ControlSwitchLogo.kt` | Compose `ImageVector`, package `com.controlswitch.ui.theme` |
| `png/control-switch-icon-{512,1024}.png` | Rounded tile renders; `-fullbleed-512` is unmasked |

## Regenerating

`gen.py` holds every number (colours, ghost alpha, shadow, spread, scale, safe-zone fit).
`pip install skia-python cairosvg`, then `python3 gen.py <out-dir>`, and copy the files across as
above. Don't hand-edit the generated XML.
